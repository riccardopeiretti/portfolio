# Data Science & Predictive Modeling

Projects applying machine learning, data analysis, and artificial intelligence techniques to solve problems across different domains, including transportation, logistics, and spatio-temporal forecasting.

### [AIS-Based Predictive Modeling of Vessel Trajectories](AIS_Based_Predictive_Modeling_of_Vessel_Trajectories.pdf)

- **Objective:**  
  Predict future vessel positions up to five days ahead using Automatic Identification System (AIS) data, combining vessel characteristics, navigation status, and port-related information.

- **Outcome:**  
  Performed exploratory data analysis and feature engineering by extracting temporal and spatial patterns, including lag features, time differences, distances, bearings, and trajectory statistics. Developed and compared machine learning models based on Random Forest, XGBoost, and LightGBM.

  The results showed that incorporating temporal and spatial features significantly improved trajectory forecasting performance, while also highlighting the challenges of predicting complex maritime movements from AIS data.

- **Skills:**  
  Python | Machine Learning | Time-Series Forecasting | Feature Engineering | Geospatial Data Analysis

### [Day-ahead Electricity Spot Price Forecasting](Day_ahead_Electricity_Spot_Price_Forecasting.pdf)

- **Objective:**  
  Develop a data-driven forecasting approach to predict day-ahead electricity spot prices using historical market data and relevant temporal features.

- **Outcome:**  
  Developed an end-to-end data science pipeline, including data preprocessing, exploratory data analysis, feature engineering, predictive modeling, and model evaluation. The project investigated different approaches for electricity price forecasting and discussed deployment considerations, including monitoring strategies for a potential real-world implementation.

- **Skills:**  
  Python | Data Analysis | Machine Learning | Time-Series Forecasting | Model Evaluation

### [Knowledge Graphs and Transportation Optimization](Knowledge_Graphs_and_Transportation_Optimization.pdf)

- **Objective:**  
  Develop a Knowledge Graph integrating heterogeneous public transportation data with educational facilities in Trentino to support mobility optimization for students and university staff.

- **Outcome:**  
  Integrated multiple data sources, including GTFS feeds, open datasets, PDFs, and web-scraped information. Defined user requirements through personas and competency questions, designed the data model through ER representations, and developed a reusable ontology-based Knowledge Graph.

  The final system enabled semantic queries for identifying suitable transportation solutions based on different user profiles and mobility needs.

- **Skills:**  
  Knowledge Graphs | Ontologies | Data Integration | Semantic Web | SPARQL

### [Recommendation Systems in Logistics](On_Recommendation_Systems_in_Logistics.pdf)

- **Objective:**  
  Investigate the application of recommendation systems in logistics, focusing on personalized route suggestions for professional drivers.

- **Outcome:**  
  Designed and evaluated multiple recommendation approaches, including collaborative filtering, content-based filtering, and hybrid methods. Applied Locality Sensitive Hashing (LSH) and K-means clustering to improve scalability and recommendation efficiency.

  The proposed approaches demonstrated the potential of personalized recommendation systems to improve route selection compared with traditional baseline strategies.

- **Skills:**  
  Recommendation Systems | Data Mining | Machine Learning | Clustering | Scalable Algorithms
